# Network Operations Training Command Center

Interactive weekly network troubleshooting practice system for TCP/IP, routing, DNS, DHCP, VLANs, NAT and Cisco Packet Tracer.

## Deployment
This folder is designed to deploy as an independent static Vercel project with the Vercel Root Directory set to `network-ops-training-platform`.

## Capabilities
- Active incident workspace
- Editable challenge library
- Lab evidence and command-plan tracking
- Runbooks
- Skills matrix and weak-area analysis
- Adaptive progression gates
- Weekly review and ranked next actions
- Evidence history
- Local browser persistence with JSON import/export

No build command or runtime secrets are required.
